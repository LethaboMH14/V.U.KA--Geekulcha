# VUKA

Help should not depend on having a free hand. VUKA is a proposed household safety system in which a person reviews consequential decisions and a separately checkable record shows what the system did. Machine learning is an input, never the authority over a person.

**You are not alone. You don't have to ask.**

## Built in this repository

- Eight sequenced audit and planning documents in [docs/audit](docs/audit/README.md).
- Seven-person work packages, coordination rules, templates and a dated work breakdown.
- Local pre-commit and CI secret-scanning configuration, plus a document contract checker.

## Designed, not built here

VIGIL: the Android phone. UMOJA: the operator service. KHAYA: the household appliance. ANCHOR: the evidence record. No application or fabricated appliance is present in this clean repository. Earlier project measurements are supplied claims, not results reproduced here; see [evidence](docs/EVIDENCE.md).

The proposed KHAYA bundle is **R299/month, modelled, not a quote**. Availability, response service, payment terms and deployment approval remain unverified. Do not use this repository as an operating safety service.
