# P2.11 — anchoring-cost reconciliation

The former R1.30/month figure is stale because it used Hedera’s pre-January-2026 message price. It must not appear in new showcase material.

For the documented batch model, 24 roots/day × 30 days = 720 roots/month. If Hedera is selected and the current `$0.0008` ConsensusSubmitMessage price is used, the network fee is `720 × $0.0008 = $0.576/month`, approximately R9–10 at the stated exchange-rate range. Hedera fees are paid in HBAR.

If OpenTimestamps remains the primary anchor, the honest prototype figure is approximately R0 in direct calendar fees because public calendars are free to use; operational availability remains a dependency. The project must select one demonstrated system before presenting a single price, show this arithmetic, and remove the stale figure from every slide and canvas.
