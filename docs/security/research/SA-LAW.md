# VUKA (pivot) — SA legal research for security/compliance plan

Scope note on the product this paper is written against: Android app, on-device duress detection (sound classification + PIN/duress-PIN), guardian alerts, **simulated** risk signal to a bank, per-user hash-chained evidence, Merkle roots anchored on **Hedera testnet**. Processes: name, SA phone number, optional Google sign-in, location at detection time, guardian contacts, device public keys. **No audio ever stored.** This is the pivoted, simpler build — not the four-layer VIGIL/UMOJA/KHAYA/ANCHOR biometric-gate design in the archived docs, so PSiRA/biometric-gate findings are noted only where they still bear (they mostly don't — no camera, no face matching, no security-service rendering).

**Repo already read:** `docs/POPIA-IO-REGISTRATION.md`, `docs/RICA-POSITION.md`, `docs/security/COMPLIANCE-GOVERNANCE.md`, and (archived, superseded by the pivot but still the source of verbatim POPIA quotes the team already captured) `archive/2026-09-four-layer/docs/POPIA-POSITION.md`, `PSIRA-POSITION.md`. `GATED-ACCESS-CODE-REVIEW.md` exists only in the archive and is about the gated-access biometric Code — not evaluated further here since VUKA (pivot) has no gate camera.

**Method note:** every row below states whether I fetched the primary/secondary text myself this session (✅ fetched) or am relying on a WebSearch synthesis I could not independently open (⚠ search-snippet only, unread primary). SAFLII and sherloc.unodc.org returned HTTP 403 to this session for every URL tried, consistent with the repo's own prior sessions. `popia.co.za` (Accessible Law, a private reformatting of the Act) was reachable and is the source for POPIA quotes; it is **not a primary source** — Government Gazette text still needed for final counsel sign-off, exactly as the existing repo docs already flag.

## Contradictions / corrections against the existing repo docs
