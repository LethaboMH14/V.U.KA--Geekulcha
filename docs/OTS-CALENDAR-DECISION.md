# P2.15 — OpenTimestamps calendar decision

Decision status: **deferred; self-hosting is not implemented.**

The project will continue to use vetted public OpenTimestamps calendars during the prototype, with timestamp state shown as pending until a proof is upgraded and independently verifiable. We must not claim that self-hosting removes the calendar dependency.

Self-hosting a calendar and running `ots upgrade` remains a future implementation task requiring an owned service, monitoring, recovery evidence, and an offline rehearsal.
