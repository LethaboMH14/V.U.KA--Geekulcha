2 · The decision pipeline — one incident, end to end

Sense
Three physically independent channels. Acoustic (mel features → YAMNet), motion (IMU windows), vehicle link (BT pairing state). Independence is the whole point — never stack correlated models and call it confidence.
Calibrate
Each channel emits a calibrated probability from a temperature-scaled head. A raw softmax entering fusion is a correctness bug, not a style issue.
Contextualise
Prior log-odds from load-shedding stage, area risk, hour-of-day, sunrise/sunset. base + β_stage·stage + β_cell·cellRisk + β_hour·hourRisk
Fuse
posterior_logodds = prior + Σ wᵢ · ln(pᵢ/(1−pᵢ))
Log-odds, not Dempster-Shafer — Zadeh's paradox breaks D-S under high conflict, and our worst cases are high-conflict (ADR-0005).
Conflict gate
Coefficient K rises when channels contradict. High K suppresses escalation and routes to verification. Disagreement is information, not noise to average away.
Escalate
L0→L3 with hysteresis — separate θ_up and θ_down per level, so state cannot chatter at a boundary. Every escalation carries a visible cancel window.
⛔ The hard boundary — ADR-0002, accepted July 2026

The machine's ceiling is watch_candidate. There is no code path in brain/fusion.py that can set state to flagged. Only human_verify() can, and it requires an authenticated operator ID. A biometric match is a lead for a human, never a verdict — because NIST FRVT documents demographic false-positive differentials up to two orders of magnitude, and in South Africa that is not academic.

Human decides
Flag · Dismiss · Whitelist. Destructive actions require two signatures — whitelist, camera disarm, threshold change, deletion. Because adding a vehicle to the whitelist makes it permanently invisible to the suspicion engine, that is the highest-value insider attack in the system.
Record
Action, actor, target, timestamp and prev_hash → SHA-256. Each entry bound to the one before it. Signed by the asserting party's Ed25519 key.
Anchor
Hourly Merkle root → public chain. 32 bytes. Not immutability — precedence: proof a record existed before anyone had a reason to falsify it.
Decay
score_now = base × 0.5^(days/7), computed at read time. No scheduler needed. It forgets you. Nobody has to decide to forgive you.

The one-sentence answer to "so you're putting biometrics on a blockchain?" — No. We anchor a hash of a hash. Deleting a person's data does not break the chain, because the chain never held it.

4 · Deployment topology

📱 Member phone
VIGIL · Android, bare RN + Kotlin
  • All inference on-device
  • Works with no signal, no power, screen off
  • Local queue, store-and-forward
  • ≤20 MB shipped models, ≤50 ms per inference on a 2 GB device
📦 Property appliance
KHAYA · sealed edge unit
  • ARM SoC + NPU, INT8 models
  • Cameras and mics on the LAN
  • 48–72 h LiFePO4 — a countermeasure, not a convenience: cutting power is step one of a break-in
  • Wi-Fi primary, LTE failover
  • Signed heartbeat into the chain
☁️ Regional service
UMOJA · FastAPI on Azure
  • WS relay, room-scoped
  • PostgreSQL + pgvector
  • Entity graph, risk cells, patrol solver
  • Rate limiting, operator auth
  • Never the decision path — sync and coordination only
⛓ Public chain
ANCHOR · OpenTimestamps → Bitcoin
  • One Merkle root per hour
  • No wallet, no token, no account
  • Chosen for longevity — a claim may go to court in ten years
  • Hedera Consensus Service as the low-latency alternative
  • ~R1.30/month for the entire network — batched, so it is a fixed cost, not per-user
detection→ on-device fusion→ WS relay→ alert render measured p50 273 ms · p95 318 ms · budget 2 000 ms

Graceful degradation is the architecture, not a feature. The camera works with no server (local queue). The server works with no vision (claims-only mode). The dashboard shows stale-marked data, never blank. Every layer defines its behaviour when the layer above it disappears.
